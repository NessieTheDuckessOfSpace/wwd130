The Ice Projects!

Apostle Spotlight!

This was the very first ICE project that I did in my WWD130 class. In this project, I learned how to use the grid property to properly align images of the Quorum of The Twelve Apostles in a nice grid. I also used a background image and pictures of the First Presidency. But mostly I learned how to use an internal style sheet and how to use a grid to make various subtle changes. It was a very worthwhile activity!

Favorite Devotional

In this activivty, I learned how to use a table. I learned how to make one in HTML and how to style it in CSS. The style sheet, in this case, was external and is linked through the head element. I was supposed to say my favorite devotionals, but I haven't actually gone to more than one at BYUI and it was difficult to remember other ones that I have gone to in the past. The focus of this activity was really to learn how best to use a table.

Christ Art Gallery!

This was an excersise in resizing images and making them more...user friendly. I didn't really need to change the HTML or CSS on this one. It was more about learning what sizes to make the images, how high-quality they need to be, and how to use online tools, like Photopea or Photoshop to tailor them specifically to my website.

Grid Flags

Oh, I loved this one. This project really focused on the things you can do with a grid. I was given some pre-set HTML elements, which I then needed to style into the various country flags. I utilized grid elements, the gap, and also a knowledge of how to set background colors in order to complete this activity. It was super fun!

HALLOWEEN!

The CSS on this one is impressive, yes? Pleased don't be impressed. I had nothing to do with it. We were specifically directed to use AI to make the wackiest CSS we could, and I really enjoyed how it came out. It gave me lots of ideas to apply to my CSS for this website.

POSITIONING :D

This was an excersize in positioning. I utilsed the grid, float, and flex properties to arrange the squares in various positions. My WDD130 professor provided a source image for each one, and the task was to make the squares on the site match the source image.

Prophet Cards

This activity was mostly to learn WHAT an internal stylesheet is, and how best to utilize it to make the site's elements match a specific source image I was given. I learned how best to use various fonts taht aren't Times New Roman and overall just how exactly to use that internal style sheet.

Signup Page

This was ALL ABOUT FORMS. I was suppposed to learn how to make and style a form on this one, and I did okay. I really learned how to utilize the z-index property, actually. It was difficult to make the site match the reference image in the necessary amount of time, but it worked!
